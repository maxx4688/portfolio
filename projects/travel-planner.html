Overview

WanderPlan helps travelers organize every detail of a trip — from flights and hotels to daily activities — in one beautifully designed mobile app. Map integration makes it easy to explore destinations and plan routes.

Built with Flutter for cross-platform delivery, the app leverages Google Maps API for location services and Firebase for user accounts and shared trip data.

RoleApp Developer
PlatformAndroid
StatusIn Development

Key Features

  • Interactive map with pinned attractions and routes
  • Day-by-day itinerary builder with time slots
  • Share trip plans with friends via invite links
  • Offline access to saved itineraries
  • Photo journal to capture and share moments
