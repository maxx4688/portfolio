Visit Live Site View on GitHub

Overview

ToDoo Web turns scattered thoughts into clear, beautiful notes and to-doos. Built as the browser companion to the ToDoo mobile app, it gives users a focused workspace to capture ideas, organize tasks, and return to what matters in seconds.

The site features a polished landing experience, authenticated todoos board, creative note fields, theme customization, and cloud-synced storage — all designed with a calm, minimal aesthetic that prioritizes clarity over clutter.

RoleFront-end Developer
PlatformWeb
StatusLive on GitHub Pages

Key Features

  • Fast note and to-do creation with card-based layout
  • Smart search, favorites, and creative fields for polished notes
  • Checklists, links, and organized todoos board after login
  • Theme controls including glass mode and grid view
  • Cloud-synced workspace accessible 24/7 from any browser
