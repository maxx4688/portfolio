Overview

Haven Craft is a brand site for curated wallpapers — AMOLED, scenery, desktop, and minimal collections presented with soft motion, editorial type, and high-fidelity device mockups.

The page guides visitors through collections, fresh category cards, the companion .PNG app, support via Buy Me a Coffee, and a contact form — all built as a static site on GitHub Pages.

RoleDesigner & Developer
PlatformWeb
StatusLive on GitHub Pages

Key Features

  • Hero storytelling with overlapping phone mockups and “We priorities elegance”
  • Collection chapters for AMOLED, Scenery, Desktop, and Minimalism
  • Fresh Collections grid with category previews
  • Companion .PNG app callout with elegance-first positioning
  • Contact form, social links, and Buy Me a Coffee support path
