Overview

To doo is a mobile productivity app focused on simple, reliable task and note management. Users can create, organize, and track daily activities with a clean interface that prioritizes speed and readability over clutter.

Built as a learning project that evolved into a fully functional Android app, it integrates Firebase for authentication and cloud sync, ensuring notes persist across sessions and devices.

RoleFull-stack Developer
PlatformAndroid
StatusPublished on GitHub

Key Features

  • Create and edit notes with a distraction-free writing experience
  • Organize tasks by date with quick daily overview
  • Firebase authentication and cloud-backed data storage
  • Responsive Material Design UI tuned for one-handed use
  • Offline-friendly local caching with sync on reconnect
