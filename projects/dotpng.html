Overview

DotPNG is a Flutter wallpaper app built around one idea: wallpapers should feel intentional. Clean grids, soft motion, palette-aware controls, and a brand identity that treats the dot as a design element — not decoration.

Wallpapers load from a Supabase backend, cache for speed, and sit in a layout closer to a design gallery than a generic store. Elegance Priority runs through onboarding, typography, and interaction design.

RoleDesigner & Developer

Key Features

  • Curated library from Supabase with cached images and shimmer loading
  • Two-column home feed, featured carousel, categories, and frosted-glass search
  • Detail view with download, set wallpaper, favorites, and 3D info flip
  • Live color palette extraction that adapts the action bar to each wallpaper
  • Light & dark themes with signature orange, crimson, and amber accents
