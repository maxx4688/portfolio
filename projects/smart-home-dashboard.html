Overview

HomeHub is a UI/UX design concept for a smart home management dashboard. The interface prioritizes clarity — letting users control lights, thermostats, security cameras, and energy monitors from a single responsive layout.

Designed in Figma with interactive prototypes in Adobe XD, the project explores dark-mode aesthetics, card-based device controls, and real-time energy consumption visualizations.

RoleUI/UX Designer
DeliverableDesign System

Design Highlights

  • Unified device control cards with status indicators
  • Energy usage charts with daily and monthly views
  • Room-based navigation for multi-zone homes
  • Automation rule builder with visual timeline
  • Responsive layouts for tablet and desktop
